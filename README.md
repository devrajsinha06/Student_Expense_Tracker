# STUDENT EXPENSE TRACKER 

## 1. Overview
Student expense tracker is a simple python command- line project for recording daily expenses,managing a monthly budget and viewing spending reports

## 2.Features
- Add an expense
- View all expenses
- Delete an expense
- Set monthly budget
- View budget and remaining amount
- Generate monthly category-wise report
- Store data permanently in JSON files 
- Input validation and unit testing

## 3.Technologies
- Python 3
- Python standard library only
- JSON file storage
- unittest

## 5.How To Run
1. Open the folder in VS code
2. Open the VS code terminal
3. Run: `python main.py`
4. Select a menu option
5. Data is saved inside the data folder

## 6.Testing
Run:
`python -m unittest test_project.py`

## 7.Requirements
Python 3. No external packages are required.
